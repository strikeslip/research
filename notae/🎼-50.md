Rough concept focuses on using the 50 Classical Pieces as the structural scaffold (melody, harmony, rhythm) and using the Seismic Data as the modulator (dynamics, tempo, timbre, distortion, and orchestration).

In this schema, the Earthquake acts as the "Ghost Conductor," forcing the orchestra to play the classical piece according to the geological energy release.

1. Conceptual Architecture

The application runs in the browser using a specialized "Mapping Engine" that sits between two data streams:

The Score Stream: MIDI or MusicXML data of the classical piece (static, ordered).

The Seismic Stream: Real-time or historic waveform data (chaotic, variable).

3. The "Seismic Conductor" Logic (Mapping Strategies)

This is the core schema where seismic variables map to musical parameters. This allows the web audio engine (e.g., Tone.js) to alter the playback.

Global Mappings (Macro-Structure)

Magnitude (Energy) → Dynamic Range & Layering:

Low Mag (< 3.0): Only the piano or solo strings play (Thin texture).

Med Mag (3.0 - 5.0): Woodwinds and light percussion join.

High Mag (6.0+): Full orchestral tutti, choir, and heavy brass enabled.

Depth (Origin) → Audio Filters & Reverb:

Shallow Quake: Bright, crisp sound. High-pass filter enabled.

Deep Quake: Muffled, distant sound. Low-pass filter + "Cathedral" reverb impulse.

Duration → Time Stretching:

The length of the seismic event stretches the duration of the classical track. A long tremor slows the piece down to a drone; a short shock plays it at hyper-speed.

Waveform Mappings (Micro-Structure)

The raw waveform array (waveform_data) is read in a loop (LFO) to modulate parameters in real-time:

P-Wave (Primary/Fast) → Attack & Staccato:

The initial P-wave spike triggers "Spiccato" (sharp/short) articulation samples.

S-Wave (Secondary/Shear) → Dissonance & Pitch:

As the S-wave hits, the engine detunes the instruments.

Logic: playbackRate = 1.0 + (seismic_amplitude * chaos_factor)

Surface Waves (Rolling) → Volume Swell (Tremolo):

The rolling motion of surface waves controls the master volume fader, creating a "breathing" or swelling effect on the orchestra.

4. Compositional Modes

The schema should support different "Interpretation Modes" selectable by the user.

Mode A: "The Erosion"

Concept: The piece starts perfect. The seismic data acts as "noise" or "interference."

Mechanism: The louder the earthquake data, the more the classical score is "bit-crushed" or fragmented. Notes start dropping out based on seismic amplitude peaks.

Mode B: "The Awakening"

Concept: The piece is silent. The seismic data provides the "energy" to play the instruments.

Mechanism: Velocity mapping. If the seismic amplitude is 0, the volume is 0. The orchestra only plays when the earth moves. A jagged seismograph creates a jagged, stuttering rhythm of Carmina Burana.

Mode C: "Harmonic Shift"

Concept: The seismic frequency determines the key signature.

Mechanism:

High-frequency earthquakes transposes the piece to Major keys / Higher octaves.

Low-frequency rumbling transposes the piece to Minor keys / Sub-bass octaves.

5. Technical Implementation Stack (Web-Based)

To build this concept without backend processing, the browser schema relies on:

Tone.js: For scheduling the classical score (Transport) and synthesizing/sampling the instruments.

MidiConvert.js: To parse the Classical Score (MIDI files) into JSON objects usable by Tone.js.

Web Audio API: For the DSP nodes (Filters, Convolvers for Reverb, Waveshapers for distortion).

Canvas / D3.js: To visualize the seismograph scrolling concurrently with the musical score.

6. Example Workflow Description

User selects Track #2 (Barber's Adagio).

User inputs a date range. The system fetches the 2011 Tohoku Earthquake data.

Initialization: The "Adagio" MIDI is loaded. The instrument is set to a synthesized String Section.

Playback:

Seconds 0-10: Seismic activity is low. The Strings play the opening notes softly, with a Low-Pass filter (underwater sound) because the quake started deep.

Second 11 (P-Wave): A sharp spike in data. The strings suddenly jump in volume. The tempo accelerates slightly.

Second 40 (Surface Waves/Peak): Magnitude 9.0 data hits. The "Mapping Engine" triggers the "Full Distortion" flag. The string samples are layered with a synthesized sub-bass sine wave. The playback speed wavers (simulating a warped vinyl record) matching the literal up-and-down motion of the ground.

Ending: As the aftershocks fade, the music returns to a whisper, utilizing the natural decay of the Barber Adagio.
